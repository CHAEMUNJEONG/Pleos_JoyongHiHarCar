# Quiet Drive 구현·검증 계획

**목표:** 현재 재생 중인 차량 미디어를 대화와 R단에 맞춰 낮추고, 운전석 집중 모드를 제공한다. 차량/에뮬레이터/화면 시연의 능력을 정직하게 구분한다.

**구현 결정:** 공식 Pleos SDK의 지원 언어인 Java를 사용한 Android Automotive 네이티브 앱. 외부 음악 플레이어를 만들지 않는다. 오디오·기어 권한을 먼저 검사하며, 권한 거부 시 화면 시연으로 자동 전환하지 않는다. 사용자가 별도로 선택한 시연 모드만 가상 상태를 사용한다. Rust로 Android 권한 제한을 우회할 수는 없으므로 이 버전의 플랫폼 연동 및 정책 엔진은 Java로 구현한다.

## 공통 제약

- minSdk 28, target/compileSdk 34. 경고·안내 음량은 쓰지 않는다.
- media usage의 볼륨 그룹이 안전 관련 usage와 분리되었을 때만 차량 볼륨 제어를 허용한다.
- 일반 앱에 허용되지 않는 privileged 권한을 강제로 획득하거나 시스템 앱으로 설치하지 않는다.
- 녹음은 사용자가 화면에서 기능을 켤 때 시작하는 microphone foreground service에 한정한다. 오디오는 메모리에만 존재하며 보관·전송·전사하지 않는다.
- 음성 감지는 실험 단계로 표시한다. AEC가 있어도 보컬/라디오와 모든 좌석 발화를 완벽하게 구분한다고 주장하지 않는다.
- fader/balance 원래 값의 신뢰 가능한 읽기가 불가능하면 자동 복원 기능을 실제 연동으로 제공하지 않는다.

## 구성

- `app/.../AudioPolicy.java`: 시간 기반 상태 엔진, 조건 조합, 수동 조작 양보, 램프 및 복원.
- `app/.../PositionPolicy.java`: 축별 수동 변경 존중 및 복원.
- `app/.../VehicleBridge.java`: 표준 AAOS Car API 연결, 권한/미디어 그룹 검사, 기어 구독. 지원 불가 원인 반환.
- `app/.../VoiceMonitor.java`: AudioRecord, AEC/NS, 실험용 비전사 VAD.
- `app/.../AutomationService.java`: foreground lifecycle, 단일 이벤트 순서, 실제/시연 상태 격리.
- `app/.../MainActivity.java`: 한국어 가로 화면, 세 토글, 상태와 원인, 일시중지, 주차 시 설정, 명시적 시연 패널.
- `tests/PolicyTest.java`: 의존성 없는 실제 정책 회귀 검증.
- `scripts/`: 빌드·설치·환경 진단.

## 작업 순서와 완료 기준

- [x] 환경: Android SDK API34 및 Pleos ARM 에뮬레이터 설치/부팅, 버전·해상도·권한 증거 저장.
- [x] 정책: 대화/R 동시 적용은 min 계수 1회, 침묵 대기, R 반복 전환, 램프, pause/off, 수동 볼륨 우선 및 축별 소유권 테스트를 먼저 실패시키고 구현 후 통과.
- [x] 플랫폼: 권한·안전한 media 그룹 검사, 표준 AAOS 기어 읽기 연결, 마이크 foreground service, 실패 상태를 UI로 전달. 실제 오디오 특권 미승인 및 Console R 브리지 503은 차단 상태로 남김.
- [x] 화면: 세 기능/설정/현재 감소 이유/마이크 상태, 시연 모드 명시, 운전 중 세부 설정 제한.
- [x] 검증: JVM 테스트, Android lint, debug/release APK 빌드, Pleos 설치/시작, UI 터치 시나리오, 실제 기어 콜백, 짧은 마이크 백그라운드 유지 및 권한 거부 점검. 특권 오디오·실차 발화 품질은 미검증으로 명시.

## 검토 집중 항목

1. 외부 수동 볼륨 변경 후 이전 값으로 되돌리지 않는가.
2. 대화와 R 중 하나만 종료돼도 낮은 음량을 유지하는가.
3. 연결/마이크가 끊기거나 서비스가 중지될 때 안전하게 소유권을 해제하는가.
4. 실제 지원 불가를 시연의 성공으로 오인하게 표시하지 않는가.
5. fader/balance getter 부재 및 안전 usage 공유를 차단하는가.
